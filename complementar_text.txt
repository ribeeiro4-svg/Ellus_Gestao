MÓDULO A — ATIVO IMOBILIZADO
Cadastro completo · Depreciação mensal automática · Relatórios NBC TG 27 · Baixa e reavaliação
O módulo de Ativo Imobilizado é a espinha dorsal do controle patrimonial de qualquer associação.
Sem ele, é impossível gerar o Balanço Patrimonial correto, calcular a depreciação conforme a NBC
TG 27 e cumprir as obrigações do SPED Contábil. Este módulo implementa o ciclo completo de
vida de cada bem.

A.3 Server Action — Cálculo e Geração Automática de Depreciação
Função executada automaticamente no fechamento de cada mês (ou disparada manualmente pelo
Contador):
// lib/actions/depreciacao.ts
'use server'
export async function processarDepreciacaoMensal(competencia: string) {
// competencia = 'YYYY-MM-01'
const supabase = createServerActionClient({ cookies })
const { data: { user } } = await supabase.auth.getUser()
// 1. Busca todos os bens ativos com depreciação pendente para a competência
const { data: bens } = await supabase
.from('ativos_imobilizados')
.select('*')
.eq('status', 'ativo')
.lte('data_inicio_depreciacao', competencia) // iniciou antes ou no mês
.not('grupo', 'eq', 'terrenos')
const resultados = []
for (const bem of bens ?? []) {
// 2. Verifica se já foi processado neste mês (UNIQUE constraint)
const { data: existe } = await supabase
.from('depreciacao_mensal')
.select('id').eq('ativo_id', bem.id).eq('competencia', competencia).single()
if (existe) { resultados.push({ id: bem.id, status: 'ja_processado' }); continue }
// 3. Calcula cota mensal (método linear)
// Cota = (Valor Aquisição - Valor Residual) / Vida Útil em Meses
const base = bem.valor_aquisicao - bem.valor_residual
const cotaMensal = parseFloat((base / bem.vida_util_meses).toFixed(2))
// 4. Verifica se já está totalmente depreciado
const novaAcumulada = bem.depreciacao_acumulada + cotaMensal

if (bem.depreciacao_acumulada >= base) {
resultados.push({ id: bem.id, status: 'totalmente_depreciado' }); continue
}
// 5. Ajusta a última cota (não pode ultrapassar a base depreciável)
const cotaFinal = Math.min(cotaMensal, base - bem.depreciacao_acumulada)
const acumuladaFinal = bem.depreciacao_acumulada + cotaFinal
const valorContabil = bem.valor_aquisicao - acumuladaFinal
// 6. Gera a partida contábil D: Despesa Deprec. / C: Deprec. Acumulada
const { data: partida } = await supabase.from('livro_diario').insert({
associacao_id: bem.associacao_id,
competencia: competencia,
historico: `Depreciação mensal — ${bem.descricao}
(${bem.codigo_patrimonio})`,
conta_debito_id: bem.conta_deprec_id, // D: Dispêndios com Depreciação
conta_credito_id: bem.conta_deprec_ac_id, // C: Depreciação Acumulada
valor: cotaFinal,
tipo_origem: 'auto_depreciacao',
usuario_id: user!.id,
}).select().single()
// 7. Registra na tabela depreciacao_mensal
await supabase.from('depreciacao_mensal').insert({
ativo_id: bem.id, associacao_id: bem.associacao_id,
competencia, valor_deprec_mes: cotaFinal,
deprec_acumulada_ap: acumuladaFinal,
valor_contabil_ap: valorContabil,
partida_id: partida?.id, lancamento_gerado: true,
})
// 8. Atualiza o bem com os novos saldos
await supabase.from('ativos_imobilizados').update({
depreciacao_acumulada: acumuladaFinal,
valor_contabil: valorContabil,
// Marca como totalmente depreciado se chegou ao fim
status: acumuladaFinal >= base ? 'ativo' : 'ativo', // permanece ativo
}).eq('id', bem.id)
resultados.push({ id: bem.id, status: 'processado', cota: cotaFinal })
}
// 9. Registra na audit_trail
const processados = resultados.filter(r => r.status === 'processado').length
await supabase.rpc('registrar_auditoria', {
p_modulo: 'contabil', p_acao: 'AUTO_DEPRECIACAO',
p_descricao: `Depreciação automática ${competencia}: ${processados} bens
processados.`,
// ... demais campos
})
return resultados
}

CREATE TABLE centros_custo (

associacao_id UUID NOT NULL REFERENCES associacoes(id),

nome TEXT NOT NULL, -- ex: 'Projeto Inclusão Digital 2025'

centro_custo_id UUID REFERENCES centros_custo(id);
-- View para relatório de dispêndios por centro de custo
CREATE OR REPLACE VIEW dispendios_por_cc AS
SELECT
cc.nome AS centro_custo,
pc.codigo AS conta_codigo,
pc.nome AS conta_nome,
DATE_TRUNC('month', ld.competencia) AS mes,
SUM(ld.valor) AS total_dispendio
FROM livro_diario ld
JOIN centros_custo cc ON cc.id = ld.centro_custo_id
JOIN plano_contas pc ON pc.id = ld.conta_debito_id
WHERE pc.codigo LIKE '4.%' -- Grupo Dispêndios (5.x também)
GROUP BY cc.nome, pc.codigo, pc.nome, mes
ORDER BY mes DESC, cc.nome;

C.1 DFC — Demonstração dos Fluxos de Caixa (Método Direto)
A ITG 2002 (R1), Item 28, exige o Método Direto para entidades sem fins lucrativos. Este método
classifica as entradas e saídas efetivas de caixa e bancos por natureza, agrupadas em três
atividades:
Estrutura da DFC — Método Direto (ITG 2002 R1)
• ATIVIDADES OPERACIONAIS: Recebimento de mensalidades, recebimento de doações,
recebimento de subvenções, pagamento a fornecedores, pagamento de pessoal, pagamento de
encargos, impostos pagos, IRRF recolhido
• ATIVIDADES DE INVESTIMENTO: Aquisição de imobilizado, recebimento de alienação de bens,
aplicações financeiras, resgates de aplicações, aquisição de intangíveis
• ATIVIDADES DE FINANCIAMENTO: Empréstimos captados, amortização de empréstimos,
doações patrimoniais recebidas
• RECONCILIAÇÃO FINAL: Saldo inicial de caixa e bancos + Variação líquida = Saldo final de caixa e
bancos
• VERIFICAÇÃO: Saldo final da DFC deve ser EXATAMENTE igual ao saldo contábil das contas de
disponibilidades
Mapeamento das Contas do Plano para a DFC
-- View para gerar a DFC automaticamente a partir do livro_diário
-- Classifica cada movimento pela conta contábil movimentada
CREATE OR REPLACE VIEW dfc_movimentos AS
SELECT
ld.competencia,
ld.historico,
ld.valor,
CASE
-- ATIVIDADES OPERACIONAIS

le.conta_debito_id, pd.nome, le.conta_credito_id, pc.nome,
1 - (le.embedding <=> p_historico_embedding) AS sim,
ARRAY_AGG(le.historico_text ORDER BY sim DESC) AS exemplos

ORDER BY AVG(1 - (le.embedding <=> p_historico_embedding)) DESC
LIMIT p_limit;
